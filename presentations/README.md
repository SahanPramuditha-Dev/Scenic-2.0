# Scenic presentations

Presentation sources live here so the group can version slide content like code.

## Files

- SCENIC_2_PROJECT_DECK.md — detailed proposal/final deck source.

## Workflow

1. Edit slide content through a docs branch and pull request.
2. Replace mockup placeholders with real screenshots as the UI becomes available.
3. Keep claims consistent with implemented features and test evidence.
4. Export to PowerPoint/Google Slides only when the group is preparing the actual presentation.
5. Store large exported binaries only when necessary; the Markdown source remains the canonical editable copy.
