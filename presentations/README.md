# Scenic presentations

Presentation sources live here so the group can version slide content like code.

## Files

- `SCENIC_2_PROJECT_DECK.md` — detailed proposal/final deck source covering product, UI areas, tracking, franchise/universe progress, intelligence, architecture, workflow and demo.
- `SCENIC_2_GROUP_KICKOFF.md` — concise kickoff deck for aligning the group on MVP scope, architecture, workstreams, Git workflow and first actions.

## Workflow

1. Edit slide content through a docs branch and pull request.
2. Replace mockup placeholders with real screenshots as the UI becomes available.
3. Keep claims consistent with implemented features and test evidence.
4. Use the kickoff deck for internal alignment; use the project deck for proposal/final presentation work.
5. Export to PowerPoint/Google Slides when the group is preparing the actual presentation.
6. Store large exported binaries only when necessary; the Markdown source remains the canonical editable copy.
