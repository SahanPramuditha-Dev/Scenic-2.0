## Routine
- Weekly planning: select achievable items and identify dependencies.
- Short progress updates: completed work, next task and blocker.
- Weekly integration demo: run the latest integrated build from `develop`; use `main` for stable milestone demos.
- Review the [risk register](RISK_REGISTER.md).
- Record consequential decisions and action owners in meeting notes.
- Escalate a blocker after one working day; pair with another member.
